A slow production app, measured before and after

At Yespark, parking rental across France, I ran a Datadog-driven query and index campaign on the slowest production paths.

Where Before After How
Worst production query 52 s < 1 ms One composite index on a 5.6 GB payments table, measured with EXPLAIN ANALYZE in prod.
Invoice listing ~100 queries 2 queries An ActiveStorage N+1, preloaded away.
Admin and API endpoints, p95 6-16 s < 3 s Partial indexes, cached aggregates, and OR-of-subqueries rewritten into index-backed BitmapOr plans (conservative estimate).
